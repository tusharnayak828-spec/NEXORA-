# Nexora Technologies website
Responsive static agency website for AI, custom software and business automation.

## Run locally
Open `index.html` in a browser. No build step or framework is required.

## Before publishing
- Replace `hello@nexoratechnologies.in` in `index.html` and `script.js` with your verified business email.
- Add your verified phone number, official social profiles and registered office details if desired.
- The contact form opens the visitor's email application. It does not store submissions; connect a backend or CRM for production lead capture.
- The portfolio tiles are demo concepts, not completed client projects. Keep the disclosure or replace them with real case studies you have permission to publish.
- Verify legal name availability and company status before representing Nexora as an incorporated company.
- This is a static site and can be deployed to any static hosting provider.
