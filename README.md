## Technical notes and limitations
- Flask application with SQLite and static HTML/CSS/JavaScript product demos.
- Demo and enquiry records currently use SQLite. On the current Render free instance, local storage is not durable and can be lost on restart or redeploy.
- DocuMind extracts text from supported PDF/TXT files and uses heuristic field detection. Scanned-PDF OCR and AI-model extraction are not connected.
- Demo API routes are publicly reachable and are not intended for confidential or production use.
- Do not upload confidential customer documents or personal data.

## Before production client use
Configure durable managed database storage, secure secrets, authentication and role-based authorization for every business API, rate limiting, audit logs, backups, monitoring, file validation and malware scanning. Review privacy and contract terms with qualified professionals.
