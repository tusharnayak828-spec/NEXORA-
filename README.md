## Capability and privacy notes
- Demo records may use the app's current database; on the current Render free instance, local SQLite storage is temporary and can be lost on restart or redeploy.
- DocuMind extracts text from supported PDF/TXT files and uses heuristic field detection. Scanned-PDF OCR and AI-model extraction are not connected.
- Do not upload confidential customer documents or use this demo as a production system.
- Production deployment should add durable managed storage, authentication, role-based access, audit logs, backups, monitoring and validated integrations.
